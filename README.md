# Enterprise Network Security Architecture

## Overview

This repository contains multiple enterprise network security implementations and infrastructure hardening projects developed using Cisco Packet Tracer and Cisco IOS technologies.

The projects focus on practical enterprise networking, routing, authentication, monitoring, VPN connectivity, access control, and layered infrastructure security within simulated multi-branch enterprise environments.

This is an academic, simulated environment (Cisco Packet Tracer) built as team coursework. It is not a production enterprise deployment. The repository includes two technical reports documenting two project milestones: the initial network design and security configuration (Milestone 1) and the multi-branch expansion (Milestone 2).

# Included Reports

## 1. Milestone 1 — Complete Network Security Report
`complete-network-security-report.pdf` (76 pages, April 2026). Cisco Packet Tracer configuration guide for the initial enterprise infrastructure, covering:
- OSPF dynamic routing
- TACACS+ AAA authentication
- SYSLOG monitoring
- SSH hardening
- ACL enforcement
- IPS deployment
- DMZ segmentation
- Infrastructure verification

## 2. Milestone 2 — Network Expansion
`Enterprise_Network_Security_Architecture_Report.pdf.pdf` (38 pages, dated May 13, 2026). Integration of a new operational branch into the existing network, covering:
- VLAN-based segmentation
- OSPF Area 0 routing and WAN connectivity
- Site-to-site IPsec VPN
- TACACS+ AAA and SSH v2 hardening
- Switch port security with sticky MAC addressing
- Centralized SYSLOG and verification commands
